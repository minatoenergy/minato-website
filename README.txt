MINATO ENERGY SYSTEMS — STATIC WEBSITE
=======================================

Files:
- index.html
- solutions.html
- swapenergy.html
- about.html
- styles.css
- script.js
- assets/

Nginx:
1. Copy this folder to your web root, for example /var/www/minatosystems.com/
2. Point the Nginx server block root to that folder.
3. Set index index.html;
4. Reload Nginx.

The site is static HTML/CSS/JS and does not require a database or application server.

Content was based on the Minato Energy Systems pitch deck supplied for this project
